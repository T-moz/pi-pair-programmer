# Pi Pair Programmer

A TypeScript extension for [Pi](https://pi.dev/docs/extensions).

## Try locally

Requires Node.js 22.19 or newer.

```sh
npm install
./node_modules/.bin/pi --extension ./src/index.ts
```

Run `/pair-programmer` in Pi. For development checks, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Install as a Pi package

```sh
pi install ./path/to/pi-pair-programmer
```
